# Photos des collections (page d’accueil)

Déposez ici une photo par collection. **Le nom du fichier est le slug de la collection** (celui de l’adresse `/products?col=...`), par exemple `mon-slug.jpg`.

Formats acceptés : jpg, png, webp, avif. Idéalement carrées, 600 × 600 px minimum, avec un vrai décor (pas de fond blanc).
Une photo absente = l’image actuelle (photo produit) est conservée, fondue dans le fond beige.
