# Photos des catégories (page d’accueil)

Déposez ici une photo par catégorie. **Le nom du fichier est le slug de la catégorie** :

| Catégorie | Fichier |
|---|---|
| Électronique | `electronique.jpg` |
| Maison & Cuisine | `maison-cuisine.jpg` |
| Mode homme | `mode-homme.jpg` |
| Mode femme | `mode-femme.jpg` |
| Enfants & Bébé | `enfants-bebe.jpg` |
| Beauté & Soins | `beaute-soins.jpg` |
| Auto | `auto.jpg` |
| Sports & Plein air | `sports-plein-air.jpg` |
| Jouets & Jeux | `jouets-jeux.jpg` |
| Animaux | `animaux.jpg` |
| Voyage | `voyage.jpg` |
| Bureau | `bureau.jpg` |
| Bricolage | `bricolage.jpg` |

Formats acceptés : jpg, png, webp, avif. Idéalement carrées, 600 × 600 px minimum, avec un vrai décor (pas de fond blanc).
Une photo absente = l’image actuelle (photo produit) est conservée, fondue dans le fond beige.
