# AMIRCAL

Marketplace e-commerce multi-catégories (USD / HTG) — Next.js, Supabase, Render.

## Démarrage

1. `cp .env.example .env.local` et renseignez les variables Supabase.
2. `npm install`
3. `npm run dev`

Le schéma de base de données est dans `supabase/migrations/`.
Les secrets (clé service_role, clés Zendrop) ne vont que dans les variables d'environnement serveur de Render.
